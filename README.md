## INSTALLATION 

1. ``` git clone https://github.com/devyverse/temp-auto-html-css-js.git  ``` 
2. In the terminal (cmd)  ```make ```
3. ```cd bin/ ```
4. ```./main ```
5. ```cd website ```
6. Your templates HTML/CSS/JS  " READY !"

## ARCHITECTURE 

```shell
/temp-auto-html-css-js
	|--/bin 
	|--/src
		|--webg.c
	|--/lib 
		|--html.h
		|--css.h
```

# PREREQUIRES

- GCC compiler should be to install 

# INSTALLATION 

1. ```shell git clone ```
2.  In the terminal  ```shell make ```
3. ```shell ./main ```
4. Completed the files HTML/CSS/JS for website template
